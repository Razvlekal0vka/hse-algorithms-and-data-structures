# Task 05. Так учиться не надо

Ограничение времени: 1 секунда  
Ограничение памяти: 64 Мб

Один из студентов Центрального Университета не любит математический анализ, в связи с чем решает задачи из листочков выборочно. У студента есть N листков бумаги с условиями задач домашней работы, пронумерованных сверху вниз от 1 до N. На некоторых из них под условиями он записывает решение задачи.

Первую задачу студент как-то решает и убирает лист с условием и решением из стопки, вторую выбрасывает не глядя, третью — кладёт вниз стопки. Далее процесс продолжается аналогично, пока задачи в стопке листов не закончатся.

Определите, будет ли задача с номером K решена или выброшена, а также номер шага, на котором это произойдёт. Одним шагом является каждая из трёх операций, описанных выше.

## Формат ввода

Первая строка входных данных содержит целое число N, вторая строка — целое число K (1 ≤ N ≤ 10^9, 1 ≤ K ≤ N).

## Формат вывода

В первой строке выведите «Yes», если задание с номером K будет подписано, и «No», если оно будет выброшено.

Во второй строке выведите номер шага, на котором это произойдёт.

## Пример 1

Ввод:

```
4
3
```

Вывод:

```
No
5
```

## Пример 2

Ввод:

```
5
3
```

Вывод:

```
Yes
7
```

## Примечания

В первом примере из условия в стопке находятся 4 задачи: (1, 2, 3, 4). Задача 1 решается, задача 2 выкидывается, задача 3 перекладывается в конец. После выполнения трёх шагов в стопке будут задачи (4, 3). Поэтому на пятом шаге задача 3 будет выброшена.

Во втором примере из условия стопка имеет вид (1, 2, 3, 4, 5). После выполнения трёх шагов стопка будет иметь вид (4, 5, 3). За следующие три шага задача 4 будет решена, задача 5 будет выброшена, а задача 3 — переложена в конец стопки (в которой ничего не будет, кроме задачи 3). Поэтому после шести шагов стопка будет иметь вид (3). На седьмом шаге задача 3 будет решена.
