# Task 01. Световые лампы

Ограничение времени: 0.5 секунд  
Ограничение памяти: 512 Мб

На посвящении студентов Центрального университета работают три световые лампы, которые поочерёдно работают в следующем порядке: левая, средняя, правая, средняя, левая, средняя, правая, средняя и т.д. Каждая лампа горит в течение одной секунды.

Известно, что лампа слева имеет ресурс A секунд горения, средней — B секунд, правой — C секунд. Определите, сколько максимально по времени будут гореть лампы.

## Формат ввода

Программа получает на вход три целых неотрицательных числа A, B, C — время горения левой, средней, правой световой лампы.

## Формат вывода

Программа должна вывести одно целое число — число секунд, которое максимально будут гореть лампы в цепочке.

## Пример

Ввод:

```
3
3
3
```

Вывод:

```
7
```

## Примечания

В примерном тесте лампы горят в следующем порядке: левая, средняя, правая, средняя, левая, средняя, правая. После этого должна загореться средняя лампа, но она уже выработала ресурс и загореться не сможет. Поэтому процесс обрывается после 7 секунд.

Для решения данной задачи на полный балл необходимо добиться сложности алгоритма в O(1).
