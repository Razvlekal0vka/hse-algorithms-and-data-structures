# Task 03. Заказ с умом

Ограничение времени: 0.5 секунд  
Ограничение памяти: 64 Мб

Необходимо купить M ручек. В некотором интернет-магазине можно сразу добавить в заказ упаковку из любого числа ручек от 1 до N. Однако, нельзя добавлять в заказ упаковки с одинаковым количеством ручек.

Например, если нужно купить M = 12 ручек, а максимальное число ручек в упаковке N = 10, то можно добавить в заказ упаковку из 7 ручек и упаковку из 5 ручек, но нельзя добавить две упаковки из 6 ручек.

Какое минимальное число упаковок может быть при заказе на M ручек в таком случае?

## Формат ввода

Первая строка входных данных содержит число N — максимальный размер одной упаковки (1 ≤ N ≤ 10^9).

Вторая строка входных данных содержит целое число M — необходимое количество ручек в заказе (1 ≤ M ≤ 10^9).

## Формат вывода

Программа должна вывести одно или несколько чисел от 1 до N — размеры выбранных упаковок в любом порядке. Если имеется несколько возможных решений, то выведите любое из них. Если решения не существует, необходимо вывести одно число «0».

## Пример 1

Ввод:

```
10
12
```

Вывод:

```
10
2
```

## Пример 2

Ввод:

```
2
5
```

Вывод:

```
0
```

## Примечания

На данную задачу существует красивое решение за O(√M).
