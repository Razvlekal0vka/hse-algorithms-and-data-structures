# Task 02. Постеры

Ограничение времени: 1 секунда  
Ограничение памяти: 512 Мб

В новом общежитии ЦУ комнаты пронумерованы от 1 до n. Ульяне необходимо расклеить рекламу мероприятия в виде постеров на двери некоторых комнат. Поскольку постеров оказалось меньше, чем комнат, Ульяна сначала наклеила постеры на каждую дверь, номер которой делился без остатка на некоторое число a. После этого оставшиеся постеры были наклеены на двери, номер которых делился без остатка на b. При этом, если на дверь уже был наклеен постер, её необходимо пропустить. Сколько всего постеров расклеено таким образом?

## Формат ввода

Три строки содержат три натуральных числа: n — количество комнат на этаже, a и b — выбранные Ульяной числа. Все числа не превосходят 10^9.

## Формат вывода

Выведите одно неотрицательное целое число — количество расклеенных постеров.

## Пример 1

Ввод:

```
10
2
3
```

Вывод:

```
7
```

## Пример 2

Ввод:

```
5
10
20
```

Вывод:

```
0
```

## Примечания

В первом примере на этаже 10 комнат. Ульяна первым проходом расклеила пять постеров на двери, номера которых делятся на 2, то есть на комнаты с номерами 2, 4, 6, 8, 10. Вторым проходом она расклеила два постера на двери, номера которых делятся на 3, то есть на комнаты с номерами 3 и 9. Комнату номер 6 она пропустила — на двери в эту комнату постер уже висит. Всего наклеено 7 постеров.

Во втором примере Ульяна не наклеит ни одного постера.

Кроме того, подумайте, как связать комнаты с номером, делящимся на оба некоторых числа, с какой-то похожей конструкцией из математики.
