# Task 04. Клеточная анимация

Ограничение времени: 0.5 секунд  
Ограничение памяти: 512 Мб

Команда студентов решила разработать новую игру в пиксельной графике, для чего им потребовалось нарисовать анимацию из увеличивающихся клеточных фигур, которые в зависимости от кадра имеют определённую высоту и длину веток, внешне чем-то напоминающих ёлочки.

Каждому номеру кадра анимации соответствует количество ветвей с одной стороны ствола и длина самой нижней ветви фигуры. Каждая следующая верхняя ветка на одну клетку короче предыдущей. Между ветвями, а также под самой нижней и над самой верхней ветвями находится ствол фигуры шириной ровно в одну клетку. На рисунке вы видите нарисованные кадры анимации с номерами от 0 до 5.

Кадры 0–5 (по клеткам):

```
кадр 0        кадр 1        кадр 2        кадр 3

  *             *             *              *
               ***           ***            ***
                *             *              *
                            *****          *****
                              *              *
                                          *******
                                             *


кадр 4                 кадр 5

    *                     *
   ***                   ***
    *                     *
  *****                 *****
    *                     *
 *******               *******
    *                     *
*********             *********
    *                     *
                       ***********
                            *
```

На следующем спринте проекта студенты решили автоматизировать процесс рисования каждого следующего кадра анимации. Помогите научиться определять количество клеток, необходимых для создания фигуры на кадре с номером n.

## Формат ввода

Программа получает на вход одно целое число n — кадр анимации (0 ≤ n ≤ 2×10^9).

## Формат вывода

Программа должна вывести одно целое число — количество клеток для отрисовки фигуры на кадре с номером n.

## Система оценивания

Каждый тест (кроме условия) данной задачи оценивается в 0.5 балла.

Решение, правильно работающее только в случае, когда n ≤ 100, будет оцениваться не более 6 баллов.

## Пример

Ввод:

```
5
```

Вывод:

```
41
```

## Примечания

Для решения данной задачи на полный балл необходимо добиться сложности алгоритма в O(1).
