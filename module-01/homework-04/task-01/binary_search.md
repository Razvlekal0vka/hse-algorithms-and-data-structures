# Task 01. Двоичный поиск

Ограничение времени: 2 секунды  
Ограничение памяти: 256 Мб

Ввод: стандартный ввод или input.txt  
Вывод: стандартный вывод или output.txt

В первой строке даны целое число \(1 \le n \le 10^5\) и массив \(A[1 \ldots n]\) из \(n\) различных натуральных чисел, не превышающих \(10^9\), в порядке возрастания. Во второй строке даны целое число \(1 \le k \le 10^5\) и \(k\) натуральных чисел \(b_1, \ldots, b_k\), не превышающих \(10^9\).

Для каждого \(i\) от 1 до \(k\) необходимо вывести индекс \(1 \le j \le n\), для которого \(A[j] = b_i\), или \(-1\), если такого \(j\) нет.

Задача из курса «Алгоритмы: теория и практика. Методы»: https://stepik.org/course/217/syllabus

## Пример

Ввод:

```
5 1 5 8 12 13
5 8 1 23 1 11
```

Вывод:

```
3 1 -1 1 -1
```
