# Task 04. Повторяющееся число

Ограничение времени: 0.5 секунд  
Ограничение памяти: 128 Мб

Ввод: стандартный ввод или input.txt  
Вывод: стандартный вывод или output.txt

Дан массив целых чисел `nums`, содержащий \(n + 1\) целых чисел, где каждое целое число находится в диапазоне \([1, n]\) включительно.

В `nums` есть только одно повторяющееся число, верните это повторяющееся число.

Нужно решить задачу, не изменяя числа массива и используя только константное количество дополнительной памяти \(O(1)\).

## Формат ввода

Массив целых чисел из \(n + 1\) элемента через пробел. \(n \le 10^7\).

## Формат вывода

Одно число, которое повторяется.

## Пример 1

Ввод:

```
1 3 4 2 2
```

Вывод:

```
2
```

## Пример 2

Ввод:

```
3 1 3 4 2
```

Вывод:

```
3
```

## Пример 3

Ввод:

```
3 3 3 3 3
```

Вывод:

```
3
```
