# Task 05. Поиск в отсортированном массиве со сдвигом

Ограничение времени: 1 секунда  
Ограничение памяти: 64 Мб

Ввод: стандартный ввод или input.txt  
Вывод: стандартный вывод или output.txt

Дан целочисленный массив `nums`, отсортированный по возрастанию (все значения различны).

Элементы массива циклически сдвигаются на некоторое число \(k\) (\(1 \le k <\) `nums.length`), так что результирующий массив имеет вид `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]` (с индексом 0). Например, `[0,1,2,4,5,6,7]` можно сдвинуть на 3 элемента и превратить в `[4,5,6,7,0,1,2]`.

Нужно вернуть индекс искомого элемента `target` в массиве после сдвига.

Алгоритм должен работать за \(O(\log n)\).

## Формат ввода

На первой строке целое число \(n\) — размер массива (не более 10000). На второй строке сами элементы через пробел (каждый не более 10000 по модулю). На третьей строке искомое значение.

## Формат вывода

Индекс элемента или \(-1\), если элемента в массиве нет.

## Пример 1

Ввод:

```
5
2 5 6 -4 -1
-1
```

Вывод:

```
4
```

## Пример 2

Ввод:

```
4
9 -5 -4 3
9
```

Вывод:

```
0
```

## Пример 3

Ввод:

```
3
9 -1 7
7
```

Вывод:

```
2
```
