# Task 01. Сортировка бинарными вставками

Ограничение времени: 1 секунда  
Ограничение памяти: 64 Мб

Ввод: стандартный ввод  
Вывод: стандартный вывод

Нужно реализовать сортировку бинарными вставками по неубыванию и посчитать количество сдвигов соседних элементов, совершённых при сортировке. Количество сдвигов должно быть минимально.

## Формат ввода

В первой строке — одно целое число \(n\) (\(0 \le n \le 10^4\)) — количество чисел, которые надо отсортировать.

Во второй строке записано \(n\) целых положительных чисел, не превышающих \(10^9\).

## Формат вывода

Сначала выведите отсортированный массив через пробел, а затем в новой строке одно число — минимальное количество сдвигов соседних элементов, совершённых при сортировке массива.

## Пример 1

Ввод:

```
5
5 2 1 4 3
```

Вывод:

```
1 2 3 4 5
6
```

## Пример 2

Ввод:

```
5
1 2 3 4 5
```

Вывод:

```
1 2 3 4 5
0
```

## Примечания

Разрешается использовать стандартные `std::swap` и `std::vector`.

Не разрешается использовать `std::reverse`, `std::sort`, `std::lower_bound`, `std::upper_bound`, `std::binary_search` и тому подобные функции.

Если алгоритм сортировки бинарными вставками не реализован, задача будет аннулирована при просмотре работ вне зависимости от вердикта тестирующей системы.
