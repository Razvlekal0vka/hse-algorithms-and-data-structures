# Task 03. Сортировка выбором максимума

Ограничение времени: 1 секунда  
Ограничение памяти: 100 Мб

Ввод: стандартный ввод или input.txt  
Вывод: стандартный вывод или output.txt

Требуется отсортировать массив по неубыванию методом выбора максимума.

## Формат ввода

В первой строке вводится одно натуральное число, не превосходящее 1000 — размер массива. Во второй строке задаются \(N\) чисел — элементы массива (целые числа, не превосходящие по модулю 1000).

## Формат вывода

Вывести получившийся массив.

## Пример 1

Ввод:

```
1
1
```

Вывод:

```
1
```

## Пример 2

Ввод:

```
2
3 1
```

Вывод:

```
1 3
```
