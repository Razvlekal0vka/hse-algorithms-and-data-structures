# Task 06. N в степени N

Ограничение времени: 1 секунда  
Ограничение памяти: 731.5712890625 Мб

Ввод: стандартный ввод или input.txt  
Вывод: стандартный вывод или output.txt

Вам даны два целых числа \(N\) и \(M\) (\(1 \le N \le 10^9\), \(2 \le M \le 10^9\)). Вычислите остаток от деления \(N^N\) на \(M\).

## Формат ввода

Входной файл содержит через пробел числа \(N\) и \(M\).

## Формат вывода

Выведите одно число — ответ к задаче.

## Система оценивания

Решать бинарным поиском.

## Пример 1

Ввод:

```
3 1001
```

Вывод:

```
27
```

## Пример 2

Ввод:

```
10 123456
```

Вывод:

```
64000
```
