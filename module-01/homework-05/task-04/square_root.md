# Task 04. Квадратный корень и квадратный квадрат

Ограничение времени: 0.5 секунд  
Ограничение памяти: 100 Мб

Ввод: стандартный ввод  
Вывод: стандартный вывод

Найдите такое число \(x\), что \(x^2 + \sqrt{x} = C\), с точностью не менее 6 знаков после точки.

## Формат ввода

В единственной строке содержится вещественное число \(1.0 \le C \le 10^{10}\).

## Формат вывода

Выведите одно число — искомый \(x\).

## Пример 1

Ввод:

```
2.0000000000
```

Вывод:

```
1.000000000
```

## Пример 2

Ввод:

```
18.0000000000
```

Вывод:

```
4.000000000
```

## Примечания

Использовать стандартные методы для поиска нельзя. Решать вещественным двоичным поиском.
