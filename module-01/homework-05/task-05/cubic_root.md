# Task 05. Корень кубического уравнения

Ограничение времени: 1 секунда  
Ограничение памяти: 256 Мб

Ввод: стандартный ввод или input.txt  
Вывод: стандартный вывод или output.txt

Дано кубическое уравнение \(ax^3 + bx^2 + cx + d = 0\) (\(a \ne 0\)). Известно, что у этого уравнения ровно один корень. Требуется его найти.

## Формат ввода

Во входных данных через пробел записаны четыре целых числа: \(-1000 \le a, b, c, d \le 1000\).

## Формат вывода

Выведите единственный действительный корень уравнения с точностью не менее 4 знаков после десятичной точки.

## Пример

Ввод:

```
1 -3 3 -1
```

Вывод:

```
1.0000005398739177931
```
