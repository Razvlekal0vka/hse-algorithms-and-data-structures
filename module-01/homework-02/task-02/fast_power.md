# Task 02. Быстрое возведение в степень

Ограничение времени: 1 секунда  
Ограничение памяти: 64 Мб

Ввод: стандартный ввод или input.txt  
Вывод: стандартный вывод или output.txt

Возводить в степень можно гораздо быстрее, чем за n умножений! Для этого нужно воспользоваться следующими рекуррентными соотношениями: a^n = (a^2)^{n/2} при чётном n, a^n = a · a^{n-1} при нечётном n. Реализуйте алгоритм быстрого возведения в степень. Если всё сделать правильно, сложность алгоритма будет O(log n).

## Формат ввода

Вводится действительное число a и целое число n.

## Формат вывода

Выведите ответ на задачу.

## Пример 1

Ввод:

```
2
1
```

Вывод:

```
2
```

## Пример 2

Ввод:

```
2
2
```

Вывод:

```
4
```

## Пример 3

Ввод:

```
2
3
```

Вывод:

```
8
```
