# Task 01. Факториал числа

Ограничение времени: 1 секунда  
Ограничение памяти: 64Mb

Ввод: стандартный ввод или input.txt  
Вывод: стандартный вывод или output.txt

Вычислить факториал введенного числа. Если факториала числа не существует, в ответе должен быть `-`.

## Формат ввода

```
5
```

## Формат вывода

```
120
```

## Примечания

Факториал числа — это произведение всех целых чисел от 1 до искомого числа. К примеру, факториал числа 6 равен 1*2*3*4*5*6 = 720.
